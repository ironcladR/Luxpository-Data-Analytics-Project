<h1>Luxpository Data Analytics Project</h1>
The Luxpository Data Analytics Project is a data analysis pipeline built around
gameplay data collected from Limbus Company Luxcavation runs.
This data is collected through attempts to run Luxcavations quickly and develop the Luxpository. The goal is to transform manually collected optimization data into a structured dataset that can be analyzed identify trends in team performance, identity usage, and clear times.
<h2>Goals</h2>
Collect run data (Already partially done but is still being performed daily)
Organize it in a consistent format.
Clean and export the data.
Analyze it with Python.
Create visualizations and summaries.
Use the results to improve the Luxpository.
Perform continuously as Limbus Company recieves updates.
<h2>Data Tracking</h2>
Variables being tracked currently are as follows:
Date, Lux type, Teamcode, Description, Time, Sinner / identity information, and Other variables added later if needed.
<h2>Planned Workflow</h2>
<h2>Planned Workflow</h2>
Collect Lux run data including clear times, Lux type, and team composition. (Significant amounts of data have already been collected.)
Store the data in a consistent format so it can be analyzed later.
Use Python to analyze trends and compare different teams and identities.
Use the results to improve recommendations in the Luxpository.
<h2>Current Status</h2>
This project is in the initial setup phase.
The project aims to start simply and expand progressively over time.
However, much of the data has been already collected, and simply needs to be organized.
